## 질환군별 상담사 개입 경향

질환군별로도 상위 개입은 대체로 `sympathy_support`와 `clarification_reflection`에 집중되어 있었다.

| 군 | 라벨 파일 수 | 상위 상담사 개입 |
|---|---:|---|
| 우울 | 429 | 공감/지지 9,487, 명료화/반영 8,733, 인지재구성 2,913 |
| 불안 | 422 | 명료화/반영 9,862, 공감/지지 8,375, 인지재구성 3,311 |
| 중독 | 397 | 공감/지지 8,170, 명료화/반영 6,756, 인지재구성 3,104 |
| 일반군 | 239 | 명료화/반영 3,569, 공감/지지 2,113, 인지재구성 853 |

해석: 우울/중독 대화에서는 공감과 지지가 상대적으로 더 앞에 오고, 불안/일반군에서는 내담자의 말과 감각을 명료화하고 반영하는 개입이 더 두드러졌다. 모든 군에서 인지재구성은 공감/반영 이후의 3순위 개입으로 나타나, 초반부터 조언·교정을 앞세우기보다 내담자의 경험을 따라간 뒤 재구성으로 넘어가는 패턴이 확인된다.

## 칼 로저스식 상담 기법 점검

데이터 라벨과 로저스식 핵심 조건을 다음처럼 대응시켜 확인했다.

| 로저스식 요소 | 대응 라벨 | 집계 |
|---|---|---:|
| 공감적 이해 | `sympathy_support` | 28,145 |
| 명료화와 반영 | `clarification_reflection` | 28,920 |
| 비판단적 수용 | `sympathy_support`, `structuring` | 32,518 |
| 진솔한 협력 구조화 | `process_feedback`, `structuring`, `goal_setting` | 9,297 |

판단: 실제 상담사 발화 라벨에서 `clarification_reflection`과 `sympathy_support`가 가장 높게 나타났다. 따라서 이 데이터셋의 상담사는 조언이나 진단을 먼저 제시하기보다, 내담자의 말을 반영하고 감정을 지지하며, 필요할 때 구조화와 인지재구성으로 넘어가는 흐름을 많이 사용한 것으로 볼 수 있다. 기존에 적용한 칼 로저스식 대화 방향은 데이터의 상위 상담사 개입 패턴과 대체로 맞다.

## 앱 반영 내용

- `src/counselorStyle.js`를 추가해 실제 상담사 발화 수, 질문 비율, 개입 라벨 분포, 로저스식 대응 근거를 집계한다.
- `src/knowledge.js`의 AIHub 근거 컨텍스트에 상담사 스타일 학습 요약을 추가했다.
- `src/server.js`의 `/api/status`에 상담사 스타일 프로필과 가이드 문자열을 노출했다.
- `src/counselor.js`가 LLM 프롬프트용 AIHub 컨텍스트에 상담사 스타일 프로필을 포함하도록 연결했다.
- `public/app.js`의 근거 패널에 실제 상담사 대화 학습 상태를 표시하도록 했다.
