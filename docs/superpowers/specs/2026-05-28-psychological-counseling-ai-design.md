# LLM 기반 심리상담 AI 프로그램 설계

작성일: 2026-05-28

## 목표

AIHub `심리상담 데이터` 자료를 기반 지식으로 활용해 사용자가 채팅으로 심리상담을 받을 수 있는 로컬 웹앱 MVP를 만든다. 앱은 심리장애를 확정 진단하지 않고, 대화 내용 기반의 가능성 및 위험도를 추정하며, 상태별 조치와 상담 보조 세션을 제공한다.

## 핵심 기능

1. 대화형 심리상담
   - 사용자의 발화를 공감적으로 반영한다.
   - 상담사는 후속 질문, 감정 정리, 문제 명료화, 행동 계획을 제안한다.
   - 과도한 단정, 진단 확정, 약물/의학 처방은 하지 않는다.

2. 심리장애 가능성 분류
   - 우울, 불안, 중독, 일반군 기준으로 가능성을 추정한다.
   - 결과는 `높음`, `중간`, `낮음`, `근거 부족`으로 표현한다.
   - 모델 출력에는 사용자의 실제 발화 근거와 데이터 기반 참고 근거를 분리해 표시한다.

3. 강도 및 위험도 평가
   - 상담 내용에서 고통 강도, 지속 기간, 기능 손상, 위기 신호를 평가한다.
   - 위험도는 `낮음`, `중간`, `높음`, `긴급`으로 분류한다.
   - 자해, 타해, 현실 검증 저하, 즉각적인 안전 위험이 감지되면 상담을 계속 진행하기보다 긴급 도움 안내를 우선한다.

4. 조치 및 상담 보조 모드
   - 상태별로 자기점검, 호흡 안정화, 행동활성화, 인지재구성, 기록 과제를 제공한다.
   - 각 세션은 목표, 짧은 단계, 사용자의 응답, 다음 권고로 구성한다.
   - 앱은 전문 치료를 대체하지 않으며, 고위험 상태에서는 전문가 상담 또는 응급 도움을 권고한다.

## 데이터 사용

현재 저장된 자료:

- `aihub_71806/page.html`: AIHub 상세 페이지
- `aihub_71806/s3_file_list_normalized.json`: 150개 원본/라벨링 ZIP 목록
- `aihub_71806/public_files/*.hwp`: 데이터 설명서 및 활용 가이드
- `aihub_71806/final_outputs/*.zip`: 공개 접근 가능한 저작도구 및 AI 모델 산출물

원본 150개 데이터 ZIP은 AIHub 로그인 및 다운로드 승인이 필요하므로 현재 앱의 초기 버전은 다음 순서로 동작한다.

1. 저장된 설명서, 활용 가이드, 파일 목록, 모델 산출물 메타데이터를 근거 자료로 색인한다.
2. 승인된 AIHub API 키 또는 세션 기반 다운로드 방법이 사용자가 제공되면 원본 ZIP을 내려받아 색인을 확장한다.
3. 앱은 원본 데이터 유무와 관계없이 데이터 출처와 색인 상태를 UI에 표시한다.

## API 키 및 인증

앱은 Safari의 로그인 세션이나 브라우저에 저장된 비밀값을 직접 읽지 않는다. 비밀값은 사용자가 직접 `.env`에 넣는다.

예상 환경변수:

- `OPENAI_API_KEY`: LLM 응답 생성 및 분류용
- `AIHUB_API_KEY`: AIHub 원본 데이터 다운로드 또는 API 연동용, 사용자가 확보한 경우

`.env`는 저장소에 커밋하지 않는다.

## 아키텍처

로컬 웹앱 구조:

- Frontend: 상담 채팅, 위험도 패널, 근거/권고 패널, 상담 세션 모드
- Backend API: 채팅 요청 처리, 분류 요청 처리, 위험도 평가, 자료 검색
- Knowledge Index: AIHub 문서 및 데이터 인벤토리 색인
- Safety Layer: 위기 신호 감지, 금지 출력 차단, 응급 안내 템플릿
- LLM Adapter: OpenAI API 호출 래퍼, JSON 출력 검증, 오류 처리

권장 기술:

- Node.js 기반 단일 프로젝트
- Express 또는 Vite dev server
- 브라우저에서 바로 확인 가능한 React UI
- 저장소 내부 `data/` 또는 `app/data/`에 색인 파일 생성

## 데이터 흐름

1. 사용자가 상담 메시지를 입력한다.
2. Backend가 최근 대화, 사용자 메시지, 검색된 AIHub 근거를 조합한다.
3. Safety Layer가 위기 신호를 선평가한다.
4. LLM Adapter가 상담 응답, 가능성 분류, 강도 평가, 권고를 구조화 JSON으로 받는다.
5. Backend가 JSON 스키마를 검증하고 UI에 전달한다.
6. UI는 상담 응답과 함께 위험도, 가능성, 추천 조치를 표시한다.

## 출력 정책

앱은 다음 표현을 사용한다.

- 허용: `우울 관련 신호가 높게 나타납니다`, `불안 가능성이 중간 수준입니다`, `전문가 상담을 권합니다`
- 금지: `당신은 우울증입니다`, `치료가 완료됩니다`, `약을 복용하세요`

긴급 위험도에서는 다음을 우선한다.

- 혼자 있지 않기
- 가까운 사람 또는 지역 응급 서비스에 연락하기
- 한국 기준 자살예방상담전화 109 또는 응급상황 119 안내

## UI 설계

첫 화면은 마케팅 랜딩 페이지가 아니라 실제 상담 작업 화면이다.

- 좌측 또는 중앙: 채팅 대화
- 우측: 현재 위험도, 가능성 분류, 권고 조치, 사용된 근거
- 하단: 상담 모드 선택
  - 자유 상담
  - 감정 정리
  - 인지재구성
  - 행동 계획
  - 위기 안정화

운영 도구 UI처럼 차분하고 읽기 쉬운 화면을 우선한다.

## 오류 처리

- LLM API 키 없음: 로컬 규칙 기반 데모 모드로 동작하고 키 설정 안내를 표시한다.
- LLM JSON 파싱 실패: 안전한 기본 응답으로 대체하고 재시도 버튼을 제공한다.
- AIHub 원본 데이터 없음: 현재 저장된 문서 기반으로만 동작함을 표시한다.
- 위기 신호 감지: 일반 상담 응답보다 안전 안내를 우선한다.

## 테스트 전략

위험한 의료/심리 도메인이므로 최소한 다음 테스트를 둔다.

- 위기 신호 문장이 긴급 위험도로 분류되는지
- 일반 스트레스 문장이 과도하게 긴급으로 분류되지 않는지
- 진단 확정 표현이 출력에서 제거되는지
- LLM JSON 오류 시 안전한 응답으로 대체되는지
- AIHub 인벤토리 로딩이 150개 파일을 정확히 읽는지

## 구현 범위

MVP에 포함:

- 로컬 웹앱 실행
- 채팅 UI
- 4가지 핵심 기능의 동작 흐름
- AIHub 저장 자료 색인
- OpenAI API 연동
- `.env.example`
- 안전 레이어 및 테스트

MVP에서 제외:

- 사용자 계정
- 장기 상담 기록의 클라우드 저장
- 실제 의료기관 연계 자동 예약
- AIHub 승인 없는 원본 데이터 다운로드 우회
- 앱스토어/상용 배포 준비

## 승인 기준

- 사용자가 로컬에서 웹앱을 열고 상담 대화를 할 수 있다.
- 앱이 가능성 분류, 강도 평가, 조치 권고, 상담 보조를 한 화면에서 제공한다.
- 고위험 문장에는 긴급 도움 안내가 우선 표시된다.
- API 키가 없어도 데모 모드로 UI와 안전 흐름을 확인할 수 있다.
- 저장된 AIHub 자료의 사용 범위와 원본 데이터 접근 제한이 명확히 표시된다.
